Explicit Achievement-Memory PPO Network
=======================================

Inputs
------

  O_t                         achievement_progress_t
  image observation           22-d binary achievement list
  64 x 64 x 3                 1 = completed this episode
                              0 = not completed yet


Encoders
--------

  Image encoder

    O_t
      |
      v
    IMPALA CNN
      channels: [64, 128, 128]
      final map: 8 x 8 x 128
      flattened: 8192
      |
      v
    LayerNorm + Linear 8192 -> 256 + ReLU
      |
      v
    LayerNorm + Linear 256 -> 1024 + ReLU
      |
      v
    image_latent z_t
      shape: 1024


  Explicit memory encoder

    achievement_progress_t
      shape: 22
      |
      v
    LayerNorm(22)
      |
      v
    Linear 22 -> 256 + ReLU
      |
      v
    Linear 256 -> 256 + ReLU
      |
      v
    memory_latent m_t
      shape: 256


Shared Actor-Critic Input
-------------------------

      image_latent z_t              memory_latent m_t
           1024                           256
             \                             /
              \                           /
               v                         v
                   concat([z_t, m_t])
                           |
                           v
                        shared_t
                        shape: 1280


Actor
-----

  shared_t
    |
    v
  LayerNorm(1280)
    |
    v
  Linear 1280 -> 1024 + ReLU
    |
    v
  pi_latents
    shape: 1024
    |
    v
  Linear 1024 -> 17
    |
    v
  action logits


Critic
------

  shared_t
    |
    v
  LayerNorm(1280)
    |
    v
  Linear 1280 -> 1280 + ReLU
    |
    v
  vf_latents
    shape: 1280
    |
    v
  Linear 1280 -> 1
    |
    v
  scalar value V(O_t, achievement_progress_t)


Note
----

  This model has no GRU recurrence.
  The 22-d achievement list replaces the learned recurrent hidden state.
